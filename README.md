# sql-lab

Laboratorios del curso de Programación Avanzada de Base de Datos, usando SQL Server.

## Contenido

| Archivo | Tema |
|---|---|
| `dml-crud.sql` | Operaciones DML (INSERT, UPDATE, DELETE, SELECT) |
| `joins-case.sql` | JOINs y estructuras CASE |
| `subqueries.sql` | Subconsultas |
| `views-indexes.sql` | Vistas e índices |
| `stored-procedures.sql` | Procedimientos almacenados |
| `transactions.sql` | Transacciones |
| `triggers.sql` | Triggers |
| `cursors.sql` | Cursores |
| `execution-plans.sql` | Planes de ejecución |
| `northwind-db.sql` | Consultas sobre la base Northwind |
| `biblioteca-db.sql` | Consultas sobre base de datos de biblioteca |
| `security-permissions.sql` | Logins, roles y permisos de acceso |
| `backups.sql` | Copias de seguridad (backups) |

## Tecnología

- SQL Server
- SQL Server Management Studio (SSMS)

## Curso

Programación Avanzada de Base de Datos
